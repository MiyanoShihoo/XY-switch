# XY Switch 产品体验重构

日期：2026-11-06。范围：当前工作区的表现层、信息架构、导航及页面交互。第一阶段冻结 UI 代码，先保存运行截图和分析任务。此前的局部修正不作为本轮完成证据。

## 1. 产品任务与边界

XY Switch 管理本机 AI 工作环境：选择供应商及模型、把配置交付给客户端、管理账号引用、安装并授权工具、继续本地会话、理解请求用量和响应证据、控制权限与恢复配置。

以下频率均为待验证的使用假设，没有遥测：高频为切换工作环境、恢复会话、检查请求；中频为调整配置、选择工具与客户端；低频但后果重的工作为安装授权、凭据变更、恢复、删除与治理策略。

用户决策中的共同对象是“当前客户端 / 项目 / 配置 / 请求”，不是导航分组。导航用于到达任务，局部视图用于完成该对象的工作。需要保留完整路由、读写契约、字段格式、审计来源、权限审查与过期检查。所有浏览器证据使用有意义的合成数据，真实截图指运行中的 renderer，不是静态设计稿。

## 2. 当前结构的证据

改造前截图位于 ../artifacts/experience-redesign-20261106/before/ 。已保存总览、供应商/配置/编辑/诊断、客户端、账号、插件/市场/详情、MCP、提示词、Skills、会话/阅读、用量、设置、治理。

- 全局：68px 活动分组轨道加 48px 组内导航。分组会记住最近页面；跨组去非最近目的页需要先切分组，再选择页面；总览、模块页头、组内导航都有位置表达。
- 会话：桌面目录始终常驻，右侧未选择时为空；选中后正文仍在有最大宽度的内部滚动区。1440×960、18条会话/10条消息下，首条消息 y=426.22，正文宽532.59px。读者没有话题目录，跨讨论轮次依赖滚动或预先知道关键词。
- 市场：目录按类型重新分组，详情为模态框；比较另一个插件需要关详情再选项。安装前另开确认，这是必要的安全边界，不能因缩短路径而取消。
- 用量：概览、请求日志、审计和配置共用上方多层过滤区；统计行不可下钻到对应请求。已知费用和未知费用已有正确区分，但缺少“从哪个对象贡献了费用到查看请求”的连续路径。

## 4. 主要任务方案

### 会话：找回任务，然后阅读与恢复

优先级：标题及项目 > 客户端与最近活动 > 正文讨论脉络 > 恢复动作 > 来源/完整标识/管理。

- A：默认完整会话目录，支持按项目组织或按最近活动浏览；打开后切换到专注阅读工作区。阅读工作区有由用户消息生成的讨论目录、正文与固定的项目/恢复上下文；来源与危险管理按需打开。返回目录恢复选中行和滚动位置。
- B：三栏常驻工作台，项目目录、会话目录、正文始终并列。连续浏览同项目更快，但1024窗口叠加全局导航后，正文宽度和操作区明显受限。
- 选择A。目录使用全宽提高跨客户端/项目比较；阅读时不再让文件目录与正文竞争空间。讨论目录从已按需读取的消息生成，不新增全量正文读取，不伪造摘要。工具事件保持完整，状态/失败/审批信息可见，长原文可展开；正文搜索必须定位并展开匹配内容。
- 体验目标：默认不出现占半页的空阅读区；进入阅读后正文从约250px内开始；点击一个讨论项直接定位对应轮次；返回可继续原列表位置。恢复命令逐字复制，绝不执行；删除仍有独立确认。

### 插件市场：连续比较，再审查安装

优先级：用途与兼容客户端 > 候选差异 > 精确版本/发布者 > 签名与权限 > 明确客户端/确认安装。

- A：搜索结果与候选详情并列的比较工作区。左侧连续结果按服务返回顺序，右侧显示选中项；首次显示第一项仅使用已取得的目录元数据。安装预览、版本历史、下载、举报从详情进入。窄窗口详情取代列表，返回保留搜索、分页和选中位置。
- B：全宽结果目录，每条行内展开详细内容。少量候选对比方便，但多个长描述/完整技术标识展开会使后续结果不断跳动。
- 选择A。连续比较2个候选由“打开→关窗→打开”降为“选中→选中”，始终可见候选位置。未连接时直接提供来源配置；投稿/登录为次要入口，只有可用多个工作区时才显示工作区切换。
- 安装是独立审查状态，客户端、完整权限、新增权限、签名指纹、精确版本、确认复选和过期/撤回重查全部保留。方案不会自动下载、安装、信任密钥或登录。

### 用量：先看变化，再定位原因

优先级：当前筛选范围 > 请求/成功/已知费用/未知口径 > 时间变化 > 供应商和模型贡献 > 具体请求与证据。

- A：分析工作区。顶部为日期快捷范围和其他筛选；紧凑横向摘要；主要区域为趋势与可操作的对象比较。点击供应商/模型统计项直接进入相同范围的请求结果。请求列表与选中证据在大窗口并列，较窄窗口使用独立详情。
- B：单一长页面，把摘要、图表、两张统计表、日志和审计顺序排列。无需切页，但大量数据下主要分析对象相距很远，日志和探测配置容易混淆。
- 选择A。快捷日期是显式应用操作；复杂筛选仍显示草稿/已应用的区别。下钻复用原UsageFilter，保留本地来源与代理来源、零/未知、缓存口径、分页边界、响应证据来源。主动探测仍留在独立配置区，不因查看证据触发新请求。
- 体验目标：从一个供应商贡献到其请求不再手工记名称再展开筛选；图表不为大序列制造几百个难以对齐的文字标签；完整原始数据仍可读取。

### 总览：选择并核对当前工作环境

- A：工作环境选择页。当前供应商/模型形成选择摘要；候选配置能直接比较并显式切换。切换区紧邻按钮显示实际已接管的全部客户端范围，运行状态和历史测试各自说明来源。常用后续任务直接进入接入、会话和用量。
- B：工作任务首页，把最近会话、工具和连接分别放在任务区。覆盖范围广，但要为首页新增多类查询，核心切换仍需进入另一页。
- 选择A。去掉三节点示意图，以实际选择对象和下一步操作组织页面；直接复用供应商控制器的显式激活流程。未知/已停止/上次测试通过不可互相冒充。

## 5. 排版和窗口策略

共用现有语义颜色；本轮布局不依赖换色。正文14px、短元信息12px、阅读正文15px并使用适合中文的行高；只有路径/ID/代码使用等宽字，金额和计数使用等宽数字。标题、主数据、辅助解释三级明确，正文不是满屏浅灰小字。

表格用于跨对象比较，目录用于选择，阅读区用于长内容，独立有后果的操作使用对话框。无意义卡片、重复标题和为了反卡片而增加的分割线均不属于方案。明暗主题共享同一结构、密度和状态语义。

1024×768是常用小桌面验收；1280×800和1440×960为主要工作窗口；820/390/320用于重排与内容可达性检查。每页只有内容需要独立定位时才使用内部滚动，正文和页面不相互截断。

## 6. 方案审查与实施门槛

独立设计审查 Agent 不参与实现，有权否决候选。其评审须覆盖导航冗余、信息效率、层级、密度、操作路径和桌面适配；不能仅评价视觉风格。被否决部分先修改方案再实施。

审查结果及其他页面方案在研究完成后补入本文。此时 UI 代码仍保持冻结。

## 7. 验证设计成果

每个主要页面提供同内容、同窗口的运行前后截图；可用性用具体路径验证：跨组导航、同项目找会话、讨论定位/返回/复制、连续比较插件、从统计下钻请求、编辑单个配置字段、目标客户端授权及危险确认。

覆盖无数据、少量数据、大量数据、长描述/路径/标识符、中英文和明暗主题。操作次数只用于解释真实路径，不以代码量或像素差异认定完成。截图与交互无法证明原生文件、真实安装、账单或三平台打包，最终报告明确证据范围。

## 10. 实施契约与交接

### 选择与写入

总览和供应商目录使用同一 ProvidersController.activate(id)；仅明确“设为当前”触发。存在、启用、非当前、busy/testing锁均保留。未接管时切换不启动路由或创建客户端文件；有接管时后端同步所有已接管目标、校验外部修改并保留回滚错误。前端不在 await 后自行无条件宣布成功，继续显示控制器的“已切换但状态读取失败”等结果。点行/展开/排序/测试均不切换。当前配置、真实运行、客户端接管、最近测试四者分开。

供应商复制不复制凭据；编辑原凭据保留/替换/删除语义和高级字段。客户端以真实configOwner组织，共享目标和恢复备份范围保留。账号网关/原生用途分开，不把凭据展示在一般信息中。

### 资源与审核

插件权限增量与完整权限同存，授权客户端明确；审核的精确版本、完整指纹、摘要、工具、参数和票据期限绑定。权限集合替换不能改为追加。默认不启用，不支持运行的能力继续禁用；撤回/回滚/卸载原机制保留。MCP的配置挂载不等于健康；共享调用保留完整客户端范围、权限交集和一次性授权。提示词新建默认启用、复制默认停用，启用不宣称已经注入；Skills读取来源默认关闭，移除引用保留原文件。

### 设置、预算与危险操作

页面跳转不得宣称保存。敏感子任务继续按既有卸载与票据清理生命周期；需要离开未保存表单时明确丢弃或返回，不把口令/确认票据全局长期缓存。凭据页只查询存在状态。隐私草稿预览仅本地内存，输入/策略变化清旧结果。

预算保留UTC日界、精确定价、每次尝试先预留；未知/失败/取消不自动退款；取消包括未来重试。收费验收保留运行路由、启用预算、精确价格及ALLOW PAID CHECKS，固定目标且不重试/故障转移/执行返回工具，HTTP200不直接算通过。

普通配置JSON、加密交换、本地配置版本、外部文件挂载四种范围不可混同；普通导入没有逐项diff预检就不创造此功能。所有 REVOKE / ROLLBACK / WRITE FILE / DELETE VERSION / DELETE BACKUP / IMPORT / EXPORT / ROLLBACK SYNC 以及现有删除、凭据清除和恢复确认继续绑定所审对象。

## 11. 独立审查修订：明确实施条件

### 11.1 激活的实际影响范围

总览服务“核对当前工作环境并选择下一配置”；供应商目录服务“跨配置比较、维护和编辑”。总览仅展示当前选择、切换候选和影响范围，供应商目录不增加重复的当前摘要。

使用现有只读 loadAppTakeovers() / list_app_takeovers，与客户端页复用 queryKey ["takeovers"]。只以返回的 AppTakeoverStatus.active 计算实际接管范围；ProxySettings.routeTargets 只是路由配置，不作为接管证据。

- 在候选列表和“设为当前”按钮上方保留同一个可见的作用范围行。有接管时逐个显示实际目标标签，并明确切换会更新所有这些目标；列表变化不触发激活。
- 明确空集合时显示“仅更改当前配置；没有客户端被接管”。未加载、读取失败与空集合不能混同；范围未确认时先刷新状态，激活入口禁用，避免把未知写成无影响。
- 继续复用 ProvidersController.activate(id) 及 enabled/current/busy/testing 限制。保留后端的路由停止拒绝与外部修改检查；切换后读取失败保留控制器的部分成功提示。
- 验证无接管、多目标接管、范围读取失败、切换已保存但运行状态刷新失败；全部使用合成IPC，不修改真实客户端。

### 11.2 恢复动作旁的工作上下文

会话阅读页的顶部上下文由标题、客户端、完整工作目录、恢复前切换目录提示及逐字复制命令组成。完整路径默认可见，技术路径可换行，复制目录为辅助动作；无路径时明确没有目录信息，不能用项目简称替代。来源文件、内部ID、删除仍在管理区。

1024/320均以不同父目录的两个同名项目验证复制前能辨认目标。正文起点约250px的目标适用于1024及以上常规内容；320的长路径允许自然增高，以完整恢复前提和内容可达为先，不用截断来满足像素目标。

- 简单关于页等已适合任务的内容允许保留，截图报告标明“沿用”，不以移动和换色宣称重构。
