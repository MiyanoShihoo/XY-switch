# XY Switch 中文用户手册

[English](user-guide-en.md) | 简体中文 · [项目说明](../README.zh-CN.md) · [构建与打包](packaging.md)

本文对应 **1.1.0**。原生应用和浏览器预览的能力不同。Windows 安装包未签名；macOS 为 ad-hoc 签名、未经公证；Android APK 为开发签名；公开的 iOS ZIP 是 ARM64 模拟器归档，**不是 iPhone IPA**。实际测试过的平台以该版本的验证报告为准。

## 安装并选择语言

从 [Releases](https://github.com/MiyanoShihoo/XY-switch/releases) 下载对应平台的安装包和 `SHA256SUMS.txt`，核对文件的 SHA-256。Windows 提供 NSIS EXE/MSI，Linux 提供 DEB/AppImage，macOS 提供 Universal App ZIP/DMG，Android 提供 APK，iOS 提供模拟器 ZIP。本版本没有 Windows 便携 ZIP。

打开 **设置 → 通用 → 界面语言**，选择 **跟随系统 / 简体中文 / English**。跟随系统采用系统/浏览器首选语言列表的第一项：以 `zh` 开头显示中文，否则显示英文。原生偏好保存在本地数据库并同步刷新桌面托盘，浏览器预览使用 localStorage。原生保存失败会保留旧语言，可在解决提示的问题后重试。切换语言不会主动丢弃当前页面未保存的表单内容。

只翻译应用自己的标签和消息，不翻译供应商名称、提示词/Skills 正文、会话内容、模型 ID、API 载荷和原始诊断。语言偏好不会改写上游请求或改变模型选择。

## 配置上游供应商

1. 打开 **供应商**，选择客户端分组，添加预设或自定义供应商。
2. 填写该上游要求的端点、凭据和模型配置。凭据与普通配置分开保存。
3. 保存后按需执行连接测试或模型探索；保存成功本身不等于上游可用。
4. 将已启用的供应商设为当前项。点击已启用、非当前供应商的卡片会同时查看并激活；详情图标只查看。发送请求前核对当前供应商标记。
5. 按需展开模型映射、请求头和请求体覆盖。模型标识保持精确；模型探索只展示上游实际返回的列表。

“已保存”“已启用”“当前供应商”“连接成功”是不同状态。上游错误详情可能保持原文，不会因为翻译而被改写成成功结果。

## 使用代理与桌面客户端接管

本地代理启动时默认关闭。配置监听与路由后，按需显式启用，以使用 OpenAI Chat Completions、Responses、Anthropic Messages 或 Gemini 的协议适配。可以手动将自己的客户端指向界面显示的本地地址，也可以使用受支持的桌面接管。

接管与恢复适配器目前支持 **Claude Code、Codex、Gemini CLI**。其他客户端分组的图标不代表已实现接管。启用前查看目标配置，使用完毕显式恢复。桌面托盘提供显示主窗口、选择供应商和退出，**没有代理开关菜单**。

协议转换成功、工具调用兼容和模型名称匹配都属于兼容性证据，不证明上游模型权重身份。重试与故障转移可能改变实际使用的上游，应结合请求证据判断。

## 管理 MCP、提示词与 Skills

**MCP：** 新建或编辑服务器配置，选择受支持的目标客户端，显式执行导入/同步。同步会写入桌面客户端配置，移动端不可用。定义保存成功不代表对应可执行文件、传输或远端服务已可用。

**提示词：** 支持本地 Markdown 提示词的新建、编辑、删除、启用/停用。本版本**不会**将提示词同步到 `CLAUDE.md`、`AGENTS.md` 或 `GEMINI.md`。

**Skills：** 桌面来源开关默认全部关闭，按需启用或添加手动引用。扫描递归包含 `.system`，排除插件缓存。删除手动引用只移除登记，不删除源文件。翻译的是应用控件，不是 Skill 名称或正文。

## 浏览本地会话（未发布检修，2026-10-27）

当前桌面源码支持 Codex、Claude Code、Gemini CLI 的会话日志，替换了原来的空接口；已发布的 1.1.0 安装包尚不包含本节改动。

- Codex 读取 `CODEX_HOME/sessions` 和 `CODEX_HOME/archived_sessions`，未覆盖时使用 `~/.codex`。Claude 使用 `CLAUDE_CONFIG_DIR/projects/<project>/*.jsonl`，默认目录是 `~/.claude`。Gemini 使用 `GEMINI_CLI_HOME/.gemini/tmp/<project>/chats/session-*.json`，默认以用户 HOME 为根；该变量指向 HOME，而不是 `.gemini` 目录本身。
- 可按客户端筛选，按标题、ID、工作目录搜索；详情显示支持的文本和工具调用/结果，不显示图片或隐藏推理。Codex 的 `session_index.jsonl` 可覆盖已发现日志的重命名标题，但不能发现额外路径；索引限 4 MiB / 20,000 条，异常索引会提示而不阻断正常日志读取。
- 恢复命令只复制，不自动执行。先切换到记录的工作目录，再自行运行；对应客户端必须已安装，原客户端会话状态也必须仍然可用。
- 删除不可撤销，只移除指定日志；请先停止该会话。不会改写原客户端 SQLite/数据库/索引，因此原客户端可能仍显示旧条目。ID 歧义、不安全路径、坏日志或不完整扫描会阻止删除。
- 单文件上限 32 MiB、目录扫描累计读取上限 64 MiB，详情显示上限 4 MiB / 5,000 条消息。部分读取和损坏内容会明确提示，不冒充空列表成功。浏览器预览及移动端明确拒绝本机会话操作。

下面的本地用量导入是独立功能。

### 收藏与快速筛选（源码功能更新，2026-10-29）

- 点击列表星标或详情中的“收藏会话”。收藏排在列表前面，各组仍按最近活动排序；收藏操作不会切换正在查看的会话。收藏按“客户端 + 会话 ID”区分，不会混淆不同客户端的同名 ID。
- “仅看收藏”可以与客户端、标题/摘要/ID/目录搜索组合使用，按钮数量只统计当前索引中存在的收藏。搜索框中按 `Esc` 只清空搜索；“清除筛选”同时重置全部条件，并把焦点送回搜索框。
- 收藏保存在本机应用的 WebView 存储中，只增加客户端和会话标识，不复制标题、目录、源文件路径或消息正文，也不修改原会话日志。相同存储来源的窗口会同步更新；不提供跨设备同步。
- 存储不可用或格式无法识别时会提示，未保存的改动只保留在当前页面，离开或刷新前请先“重试”保存。无法识别的原记录不会被覆盖。
- 索引暂时缺少会话时保留其收藏。只有应用确认删除成功，才移除对应收藏；删除报错或返回零条时保留收藏。小屏“仅看收藏”详情中取消收藏会关闭抽屉，并把焦点送回筛选按钮。

以上为源码分支功能，不代表已有 1.1.0 安装包已更新。复现检查见[收藏功能验收说明](session-favorites-20261029.md)。

## 查看用量与模型响应证据

用量页面提供代理请求记录，并支持包括 Codex、DeepSeek Harness 在内的本地用量读取。只有实际存在时才展示 token、缓存、耗时、状态、模型与成本证据。本地会话用量不能生成真实 HTTP 状态、请求耗时或账单证据。

缺少价格或用量时应视为**未知**，不是零成本。模型自报名称与协议/工具行为不能认证模型权重。主动复核可能发送额外请求并产生费用；确认预算默认 100，范围 0–10,000，仅约束该复核机制，**不是所有上游账单的硬上限**。

### 管理模型定价（未发布检修）

1. 打开 **用量与审计 → 模型定价**。填写上游实际返回的完整模型 ID，以及输入/输出单价；单位均为 USD / 百万 token。缓存读取/写入价格可留空表示未知，`0` 才表示免费。价格须为 0–1,000,000 的有限数值。
2. 保存到本机 SQLite。自定义价格按完整 ID 精确匹配，使用相同 ID 的供应商共享该规则；不是按供应商分别定价。保存只影响后续请求和新导入记录，已记录费用及其分项快照不会重算。
3. 需要参考价格时，点击 **从 models.dev 同步参考价**。同步只访问固定 HTTPS 公开目录，不发送密钥，拒绝重定向；失败保留旧目录和自定义价格。只导入支持的文本 token 单价，媒体或阶梯计价不自动换算。
4. 参考 ID 保留 `provider/model` 前缀，不自动套用到同名裸模型。可搜索/筛选目录、点击 **采用参考价**，确认或修改模型 ID 后再保存为自定义价格。每页显示 25 条。
5. 移除自定义价格需要确认；只影响后续记录，历史快照保留。旧的内置家族参考价仅作回退粗估，不能代替上游账单；没有可用价格或必要用量时保持未知。

Codex 用量导入兼容单次与累计 token 事件，四项计数均按增量处理；缺字段、负数、异常类型或无法确定增量的记录会跳过并提示，不当作免费请求。导入失败回滚数据和水位，可重试。浏览器预览明确拒绝定价写入与同步。

## 备份普通配置与定位数据

在 **设置 → 数据** 查看当前原生进程返回的真实路径；浏览器预览不提供本机数据路径。导入前先导出普通配置，并阅读确认提示：同 ID 的记录可能被更新，路由配置也可能导入。

当前未发布源码导出 v2 配置，包含自定义价格，仍接受旧 v1 备份；v1 不能携带非空 `modelPricing`。不导出公开参考价、历史用量或费用快照。导入/导出限制为 8 MiB；供应商、提示词与 MCP 各最多 1,000 条，定价目录最多 30,000 条。支持的各段先整体校验，供应商、提示词和自定义价格在同一 SQLite 事务中提交；MCP 同步和代理监听属于外部操作，不是跨全部资源的原子事务。I/O 失败会报告部分进度并刷新界面。导入文件中的 MCP 凭据值被忽略，同 ID 的本机环境变量/请求头凭据保留；新设备仍需重新录入。

普通配置导出**不是完整凭据备份**。凭据分别使用 Windows Credential Manager、Linux Secret Service、Apple Keychain，或 Android Keystore 与私有 AES-GCM 记录。迁移设备或更换不同签名的 Android 包时，准备重新录入源凭据。卸载或清除应用数据可能移除设置与凭据。

## 平台限制与排查

- **浏览器预览：** 仅用于界面检查，不代替原生密钥库、文件系统、监听器和接管操作。
- **Linux：** 需要兼容的系统库与已解锁的 Secret Service 密钥库，托盘是否可用取决于桌面环境。
- **移动端：** 只管理自身沙盒，不能接管其他应用的 CLI、读取其 Skills 或会话目录；后台代理不能保证常驻。
- **Android 无法覆盖安装：** 独立构建的开发证书可能不同。更换安装前保留普通配置并准备源凭据，不假设任意版本均可相互升级。
- **iPhone 安装：** 模拟器 ZIP 无法安装到真机。真机构建需要 Apple 签名与匹配的描述文件，见[打包指南](packaging.md)。
- **语言保存失败：** 保留旧语言是预期行为；重试前不要假定持久化偏好和托盘已经切换。
- **上游请求失败：** 分别检查配置保存、当前供应商、代理监听、认证、协议兼容和真实响应；保留相关诊断时不要公开凭据或私有请求正文。

报告问题时请提供应用版本、系统/架构、原生或预览模式、复现步骤、预期/实际结果及脱敏错误。日期性历史报告只证明当时的源码快照，不代表以后所有版本。
