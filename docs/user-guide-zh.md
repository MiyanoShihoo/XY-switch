# XY Switch 中文用户手册

[English](user-guide-en.md) | 简体中文 · [项目说明](../README.zh-CN.md) · [构建与打包](packaging.md)

本文描述 **1.2.0** 桌面功能；未发布源码更新另有标记。当前仅维护 **Windows、macOS、Linux**。原生应用和浏览器预览能力不同。Windows 安装包未签名；macOS 为 ad-hoc 签名、未经公证。旧版移动端产物仅作历史记录保留，不再提供当前构建入口。实际测试范围以对应版本验证报告为准。

## 当前源码导航（2026-11-10）

新版默认进入客户端目录。顶栏直接提供「客户端 / 供应商 / 会话 / 工具 / 用量」；品牌按钮返回总览。右上角的「全部功能」菜单打开右侧抽屉，保留所有页面入口。窗口宽度 800px 及以下时，主导航收起，使用此菜单切换页面，选择后自动关闭。以下路径对应当前源码；旧安装包保留原有布局。

| 入口 | 主要任务 |
| --- | --- |
| 客户端 | 查看客户端目录、共享配置与独立详情，进入账号和诊断 |
| 供应商 | 管理连接配置、切换当前供应商、就地修改默认模型 |
| 会话 | 查找与预览会话，进入独立全文阅读 |
| 工具 | MCP 服务器、提示词、Skills、本地插件、插件市场 |
| 用量 | 请求概览、请求记录、审计分析、探测配置 |
| 右上角设置 / 全部功能 | 设置、账号池、连接诊断、安全与验收及全部已有页面 |
| 品牌旁的工作区菜单 | 配置工作区与只读观测的 Agent 编队独立空间（`#agents`），见 [Agent 编队指南](agent-fleet-zh.md) |

右上角的运行状态控件可展开查看路由、监听地址、目标客户端和当前配置供应商，并在原生程序中启停路由。配置选择、代理运行与历史连接结果分别呈现，缓存成功不代表当前连通。主题切换位于「全部功能」抽屉底部，也可从「设置 → 通用」调整。工作区菜单返回配置工作区时，会回到离开前的配置页面；Agent 编队提供拓扑、任务、时间线与资源的只读观测；DSH 原生重跑和恢复验收仍在进行中。

### 分组设置

从右上角或「全部功能」打开「设置」。任务目录按用途分成四组，展示当前状态和生效说明；选择任务后进入对应设置：

| 设置分组 | 分类 |
| --- | --- |
| 本机偏好 | 通用、隐私 |
| 连接与凭据 | 本地路由、凭据 |
| 配置与恢复 | 数据、加密同步 |
| 应用信息 | 关于 |

通过「返回设置任务」回到目录，并恢复入口焦点。各表单沿用自身的保存流程；未保存修改和进行中的操作受到离页保护，导入、权限与删除等操作保留各自的预览和确认步骤。

## 安装并选择语言

从 [Releases](https://github.com/MiyanoShihoo/XY-switch/releases) 下载对应平台的安装包和 `SHA256SUMS.txt`，核对文件的 SHA-256。Windows 提供 NSIS EXE/MSI，Linux 提供 DEB/AppImage，macOS 提供 Universal App ZIP/DMG。本版本没有 Windows 便携 ZIP。

打开 **设置 → 通用 → 界面语言**，选择 **跟随系统 / 简体中文 / English**。跟随系统采用系统/浏览器首选语言列表的第一项：以 `zh` 开头显示中文，否则显示英文。原生偏好保存在本地数据库并同步刷新桌面托盘，浏览器预览使用 localStorage。原生保存失败会保留旧语言，可在解决提示的问题后重试。切换语言不会主动丢弃当前页面未保存的表单内容。

只翻译应用自己的标签和消息，不翻译供应商名称、提示词/Skills 正文、会话内容、模型 ID、API 载荷和原始诊断。语言偏好不会改写上游请求或改变模型选择。

## 配置上游供应商

1. 从顶栏或「全部功能」打开 **供应商**，添加预设或自定义供应商。已有供应商可通过搜索或「全部 / 已启用 / 已禁用」筛选查找。
2. 填写该上游要求的端点、凭据和模型配置。凭据与普通配置分开保存。
3. 保存后按需执行连接测试或模型探索；保存成功本身不等于上游可用。
4. 通过「设为当前」切换已启用的供应商。名称和「配置」打开详情；模型名称打开默认模型编辑。发送请求前核对当前供应商标记。连接检查可从客户端详情或「全部功能 → 连接诊断」进入。
5. 按需展开模型映射、请求头和请求体覆盖。模型标识保持精确；模型探索只展示上游实际返回的列表。

“已保存”“已启用”“当前供应商”“连接成功”是不同状态。上游错误详情可能保持原文，不会因为翻译而被改写成成功结果。

## 使用代理与桌面客户端接管

本地代理启动时默认关闭。配置监听与路由后，按需显式启用，以使用 OpenAI Chat Completions、Responses、Anthropic Messages 或 Gemini 的协议适配。可以手动将自己的客户端指向界面显示的本地地址，也可以使用受支持的桌面接管。

接管与恢复适配器目前支持 **Claude Code、Codex、Gemini CLI**。其他客户端分组的图标不代表已实现接管。启用前查看目标配置，使用完毕显式恢复。桌面托盘提供显示主窗口、选择供应商和退出，**没有代理开关菜单**。

协议转换成功、工具调用兼容和模型名称匹配都属于兼容性证据，不证明上游模型权重身份。重试与故障转移可能改变实际使用的上游，应结合请求证据判断。

## 管理 MCP、提示词与 Skills

这些页面与「本地插件」「插件市场」并列，从顶栏 **工具** 菜单或「全部功能」进入。各工具从目录进入配置、文档或资源详情；MCP 提供目标客户端控制，Skills 的文件夹导入与平台来源授权位于「添加与来源」。安装与权限变更仍需完成预览和确认。

**MCP：** 新建或编辑服务器配置，选择受支持的目标客户端，显式执行导入/同步。同步会写入桌面客户端配置。定义保存成功不代表对应可执行文件、传输或远端服务已可用。

**提示词：** 支持本地 Markdown 提示词的新建、编辑、删除、启用/停用。1.1.0 不提供规则文件同步；1.2.0 新增下述显式挂载。保存/启用提示词本身仍然**不会自动**写入 `CLAUDE.md`、`AGENTS.md` 或 `GEMINI.md`。

**Skills：** 桌面来源开关默认全部关闭，按需启用或添加手动引用。扫描递归包含 `.system`，排除插件缓存。删除手动引用只移除登记，不删除源文件。翻译的是应用控件，不是 Skill 名称或正文。

## 使用安全与验收（1.2.0）

本节对应当前桌面源码，不属于已发布的 1.1.0 安装包。从 **全部功能 → 安全与验收** 进入：

1. **访问控制：** 停止代理并恢复已接管客户端后再修改策略。默认兼容模式不强制认证；开启后创建 `proxy` 令牌供模型客户端使用，`monitor` 令牌仅用于只读状态。令牌只显示一次，可到期或撤销；共享请求限制包含鉴权失败，最小 `/health` 存活检查除外。
2. **硬预算：** 先在「用量与审计 → 模型定价」保存实际模型 ID 的精确自定义价格，再设置并确认每日 Token/费用预留上限、单次输入/输出额度及单任务尝试/费用上限。重试、故障转移和模型复核也预扣；失败、取消与未知用量不退款，重启/改限额不清历史，每日额度按 UTC 分日，任务累计跨日保留。这是本地准入预留，不保证供应商账单；多模态、远端历史、内建联网工具和原生 Gemini 上游等未支持请求被拒绝。
3. **验收监控：** 开启预算、运行代理、选择供应商/明确模型/模式后，输入 `ALLOW PAID CHECKS` 才能执行一次收费验收或启用计划。支持 Chat、SSE、工具、Responses、Anthropic 与 Gemini 客户端路径。计划默认关闭，默认每 30 分钟、每日最多 10 次；手动与计划共用次数。只有失败/恢复发生变化时记录告警；应用退出或挂起时不保证执行。
4. **配置版本：** 手动创建快照。回滚前先停止代理、恢复接管、预览 diff、勾选已查看并输入 `ROLLBACK`。同一事务先备份当前配置；预览后发生修改会阻止回滚。快照不包含凭据库、MCP、收藏、外部文件或安全策略，不能当作完整备份。
5. **显式挂载：** 用原生目录选择器授权项目，选择已保存提示词/已授权本地 Skill 和三种根规则文件之一。点击「只预览，不写入」，核对 diff 后输入 `WRITE FILE`。预览仅 5 分钟且一次有效；原文完整备份后才原子写入。后续外部修改会阻止旧预览或旧备份直接覆盖，需重新核对。只挂载 `SKILL.md` 文本，不复制/执行脚本或安装依赖。

### 单任务预算与取消（源码功能更新，2026-11-02）

- 默认单任务最多 **12 次上游尝试、USD 0.25 费用占用**。填写 0 会阻止新的尝试；关闭硬预算后新建任务不设限，已有受保护任务继续使用历史上限。调低策略会收紧已有任务，再放宽或关闭策略不会重置累计或提高这些任务已取得的上限。
- 同一任务的应用重试、故障转移、客户端重试和模型复核共同计数。Codex 使用会话与根轮次信息；其他客户端应为同一任务持续发送相同的 `X-XY-Task-ID` 或 `Idempotency-Key`。两者同时提供时必须相同；标识缺失、不合法或冲突会在硬预算发送前拒绝。不同访问令牌的任务独立，标识以摘要保存。
- 「硬预算 → 最近任务」显示最近 50 个任务，每 5 秒刷新。详情包括任务累计、上限、每次发送/客户端请求标识、供应商、模型、路由、状态、预留、已知费用及用量完整性。勾选确认后可取消同一任务的全部并发请求与后续重试；已取消任务不会被后到响应或重启恢复。
- 未知或不完整费用继续占用完整预留，已知费用低于预留也不退款；实际费用超过预留时，将超额加入累计占用并阻断不符合上限的后续发送。已发送请求的最终账单由供应商结算。
- 「用量与审计 → 请求记录 → 请求详情」中的任务累计是该条记录生成时的快照，当前累计请查看最近任务。当前 HTTP/1 TCP 读取 EOF（包括客户端写半关闭）按取消处理；未实现写半关闭后继续等待响应。

任务预算的范围与测试证据见[单任务验收报告](task-budget-acceptance-20261102.md)。没有远程设备连接。浏览器预览不会假装保存成功。会话恢复仍然只复制命令，不执行。完整边界及真实接口未通过的证据见[治理与验收记录](governance-acceptance-20261029.md)。

## 浏览本地会话（1.2.0）

从顶栏或「全部功能」打开 **会话**。选择目录行先查看预览，再通过「阅读全文」进入独立阅读；搜索、客户端、项目和收藏筛选位于目录工具栏，「刷新索引」位于目录页头。阅读时，标题、收藏和恢复命令邻近正文，来源信息按需展开。顶部「放大阅读」打开更大的阅读弹窗，关闭后回到同一条会话的阅读位置。「返回会话目录」恢复目录筛选、滚动位置与入口焦点；窄窗口同样遵循此流程。「会话信息与管理」单独展开源信息和删除操作。

当前桌面源码支持 Codex、Claude Code、Gemini CLI 的会话日志，替换了原来的空接口；已发布的 1.1.0 安装包尚不包含本节改动。

- Codex 读取 `CODEX_HOME/sessions` 和 `CODEX_HOME/archived_sessions`，未覆盖时使用 `~/.codex`。Claude 使用 `CLAUDE_CONFIG_DIR/projects/<project>/*.jsonl`，默认目录是 `~/.claude`。Gemini 使用 `GEMINI_CLI_HOME/.gemini/tmp/<project>/chats/session-*.json`，默认以用户 HOME 为根；该变量指向 HOME，而不是 `.gemini` 目录本身。
- 可按客户端筛选，按标题、ID、工作目录搜索；详情显示支持的文本和工具调用/结果，不显示图片或隐藏推理。Codex 的 `session_index.jsonl` 可覆盖已发现日志的重命名标题，但不能发现额外路径；索引限 4 MiB / 20,000 条，异常索引会提示而不阻断正常日志读取。
- 恢复命令只复制，不自动执行。先切换到记录的工作目录，再自行运行；对应客户端必须已安装，原客户端会话状态也必须仍然可用。
- 删除不可撤销，只移除指定日志；请先停止该会话。不会改写原客户端 SQLite/数据库/索引，因此原客户端可能仍显示旧条目。ID 歧义、不安全路径、坏日志或不完整扫描会阻止删除。
- 单文件上限 32 MiB、目录扫描累计读取上限 64 MiB，详情显示上限 4 MiB / 5,000 条消息。部分读取和损坏内容会明确提示，不冒充空列表成功。浏览器预览明确拒绝本机会话操作。

下面的本地用量导入是独立功能。

### 收藏与快速筛选（当前源码）

- 打开会话后，点击阅读区顶部的“收藏会话”；放大阅读中提供相同操作。收藏排在列表前面并显示星标，各组仍按最近活动排序。收藏按“客户端 + 会话 ID”区分，不会混淆不同客户端的同名 ID。
- 点击目录工具栏的“收藏”按钮切换“仅看收藏”，可与客户端、标题/摘要/ID/目录搜索组合使用，按钮数量只统计当前索引中存在的收藏。搜索框中按 `Esc` 只清空搜索；“清除筛选”同时重置全部条件，并把焦点送回搜索框。
- 收藏保存在本机应用的 WebView 存储中，只增加客户端和会话标识，不复制标题、目录、源文件路径或消息正文，也不修改原会话日志。相同存储来源的窗口会同步更新；不提供跨设备同步。
- 存储不可用或格式无法识别时会提示，未保存的改动只保留在当前页面，离开或刷新前请先“重试”保存。无法识别的原记录不会被覆盖。
- 索引暂时缺少会话时保留其收藏。只有应用确认删除成功，才移除对应收藏；删除报错或返回零条时保留收藏。启用“仅看收藏”时取消当前会话的收藏，会清除选择、退出阅读，并关闭已打开的放大阅读弹窗，焦点回到收藏筛选按钮。

以上为源码分支功能，不代表已有 1.1.0 安装包已更新。复现检查见[收藏功能验收说明](session-favorites-20261029.md)。

## 查看用量与模型响应证据

从顶栏 **用量** 或「全部功能 → 用量与审计」进入，选择「概览」「请求记录」「审计分析」或「探测配置」。概览优先显示请求数、成功率和代理耗时，点击失败数进入已筛选的失败请求。打开请求查看详细证据，返回保留筛选和位置；页面头部的「模型定价」进入价格管理。费用与 token 分开呈现，缺少费用证据时显示未知；导入操作和较长说明按需展开。

用量页面提供代理请求记录，并支持包括 Codex、DeepSeek Harness 在内的本地用量读取。只有实际存在时才展示 token、缓存、耗时、状态、模型与成本证据。本地会话用量不能生成真实 HTTP 状态、请求耗时或账单证据。

缺少价格或用量时应视为**未知**，不是零成本。模型自报名称与协议/工具行为不能认证模型权重。主动复核可能发送额外请求并产生费用；确认预算默认 100，范围 0–10,000，仅约束该复核机制，**不是所有上游账单的硬上限**。

### 管理模型定价（1.2.0）

1. 打开 **用量与审计 → 模型定价**。填写上游实际返回的完整模型 ID，以及输入/输出单价；单位均为 USD / 百万 token。缓存读取/写入价格可留空表示未知，`0` 才表示免费。价格须为 0–1,000,000 的有限数值。
2. 保存到本机 SQLite。自定义价格按完整 ID 精确匹配，使用相同 ID 的供应商共享该规则；不是按供应商分别定价。保存只影响后续请求和新导入记录，已记录费用及其分项快照不会重算。
3. 需要参考价格时，点击 **从 models.dev 同步参考价**。同步只访问固定 HTTPS 公开目录，不发送密钥，拒绝重定向；失败保留旧目录和自定义价格。只导入支持的文本 token 单价，媒体或阶梯计价不自动换算。
4. 参考 ID 保留 `provider/model` 前缀，不自动套用到同名裸模型。可搜索/筛选目录、点击 **采用参考价**，确认或修改模型 ID 后再保存为自定义价格。每页显示 25 条。
5. 移除自定义价格需要确认；只影响后续记录，历史快照保留。旧的内置家族参考价仅作回退粗估，不能代替上游账单；没有可用价格或必要用量时保持未知。

Codex 用量导入兼容单次与累计 token 事件，四项计数均按增量处理；缺字段、负数、异常类型或无法确定增量的记录会跳过并提示，不当作免费请求。导入失败回滚数据和水位，可重试。浏览器预览明确拒绝定价写入与同步。

## 备份普通配置与定位数据

在 **设置 → 数据** 查看当前原生进程返回的真实路径；浏览器预览不提供本机数据路径。导入前先导出普通配置，并阅读确认提示：同 ID 的记录可能被更新，路由配置也可能导入。

1.2.0 导出 v2 配置，包含自定义价格，仍接受旧 v1 备份；v1 不能携带非空 `modelPricing`。不导出公开参考价、历史用量或费用快照。导入/导出限制为 8 MiB；供应商、提示词与 MCP 各最多 1,000 条，定价目录最多 30,000 条。支持的各段先整体校验，供应商、提示词和自定义价格在同一 SQLite 事务中提交；MCP 同步和代理监听属于外部操作，不是跨全部资源的原子事务。I/O 失败会报告部分进度并刷新界面。导入文件中的 MCP 凭据值被忽略，同 ID 的本机环境变量/请求头凭据保留；新设备仍需重新录入。

普通配置导出**不是完整凭据备份**。凭据分别使用 Windows Credential Manager、Linux Secret Service、macOS Keychain。迁移设备时，准备重新录入源凭据。卸载或清除应用数据可能移除设置与凭据。

## 平台限制与排查

- **浏览器预览：** 仅用于界面检查，不代替原生密钥库、文件系统、监听器和接管操作。
- **Linux：** 需要兼容的系统库与已解锁的 Secret Service 密钥库，托盘是否可用取决于桌面环境。
- **iPhone 安装：** 模拟器 ZIP 无法安装到真机。真机构建需要 Apple 签名与匹配的描述文件，见[打包指南](packaging.md)。
- **语言保存失败：** 保留旧语言是预期行为；重试前不要假定持久化偏好和托盘已经切换。
- **上游请求失败：** 分别检查配置保存、当前供应商、代理监听、认证、协议兼容和真实响应；保留相关诊断时不要公开凭据或私有请求正文。
