# XY Switch 中文用户手册

## 1. 安装与启动

使用 MSI 安装包完成安装，或解压便携版 ZIP 后运行 `xy-switch.exe`。应用启动后本地代理默认关闭，不会自动接管其他程序。

## 2. 供应商管理

在“供应商”页面选择 Claude、Codex 或 Gemini 分组。可以新增预设或自定义供应商，填写端点、模型和 API Key。API Key 仅保存到本机凭据存储，不应粘贴到备注或日志。

选中供应商后可编辑、复制、删除或调整顺序。删除前应确认当前供应商是否仍被应用接管或代理使用。

## 3. 模型探索和选择

填写兼容 API 端点与 API Key 后执行模型探索。探索完成后可从菜单选择任意模型，也可将需要的模型逐项导入高级模型映射。模型数量由服务端实际返回结果决定。

## 4. 本地代理

进入设置中的代理页面，确认监听地址为本机回环地址后再启用。只有需要协议转换、重试或故障转移时才开启代理。使用结束后可手动关闭，应用退出时也会停止代理并恢复接管配置。

## 5. MCP 管理

在“MCP 服务器”页面新增 stdio 或 HTTP 类型服务器，选择需要同步的目标应用后启用。保存时应用会尽量使用原子写入，失败时回滚原有配置。

## 6. 提示词管理

在“提示词”页面创建 Markdown 提示词，选择目标应用并启用，可同步到对应的 CLAUDE.md、AGENTS.md 或 GEMINI.md。修改前建议备份目标文件。

## 7. 系统托盘

最小化后可通过托盘查看和切换供应商。切换后应确认主界面与托盘显示一致。

## 8. 故障排查

- 无法探索模型：检查端点是否包含正确的 API 前缀，并验证 API Key 权限。
- 模型只能显示一个：重新执行探索，确认服务端返回多个模型，然后从模型菜单选择或导入。
- 请求失败：检查协议格式、模型名称、端点和代理状态。
- 端口占用：关闭占用该端口的进程，或修改本地代理端口。
- 配置异常：先关闭接管，再检查目标应用配置是否已恢复。

## 9. 隐私与安全

不要分享真实 API Key。不要公开上传 `artifacts`、数据库、日志或本地配置。应用不会在冷启动时自动开启路由代理。

## 10. 当前限制

版本 1.0.0 暂不正式提供 Skills 完整管理、完整用量统计、WebDAV 云同步、账号认证及 macOS、Linux 版本。
