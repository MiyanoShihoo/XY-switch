# XY Switch：从使用任务决定界面

> 历史方案记录：本文保存第一轮页面取舍。全局导航、会话、市场与用量等最终结构以 [产品体验重构](ui-experience-redesign-20261106.md) 及其独立审查修订为准；本版验收范围见 [1.3.0 发布验收](channel-groups-acceptance-1.3.0.md)。

日期：2026-11-06。作用范围：当前 renderer；不改变持久化格式、调用契约、凭据边界和危险操作确认。

## 依据与判断方法

本轮没有使用频率遥测。下表的高/中/低是根据操作性质提出的工作假设，不能当成实际用户统计。依据来自当前功能代码、真实渲染截图和已有浏览器交互检查。截图使用具有业务含义的合成数据，不读取用户真实密钥、会话或账单；“实际截图”指运行中的界面，不是设计稿。

每页先回答：来这里完成什么 → 比较哪些信息 → 做什么决定 → 执行后如何确认。只对有具体信息或操作障碍的部分改动。主 Agent 选择下列方案；没有要求逐页批准。A/B 比较的是结构和操作路径，不是色彩主题。

## 主流程的布局选择

| 页面 / 频率假设 | 任务、决策顺序与优先级 | A：布局与取舍 | B：布局与取舍 | 主 Agent 选择及依据 |
| --- | --- | --- | --- | --- |
| 全局导航 / 高 | 回到最近任务；先选择连接、扩展、记录或设置领域，再选目的页。当前页和路由状态优先。 | 14 项固定纵向目录：任意页一步到达；名称完整，但持续占据较大横向空间，低频治理入口与高频入口同权。 | 5 个任务分组 + 组内目的页：同领域切换直接，保留最近页；跨领域多一步，但给表格和阅读留出宽度。 | B；现有连接/工具/记录的目的页存在明确共同任务。只把总览的单项“导航”改为非交互位置说明。移动端保留完整目录。该分组效率仍是假设，未来可用跨组跳转数据检验。 |

| 供应商配置详情 / 中 | 核对当前保存内容、模型映射和连接能力；选择编辑、复制或诊断。 | 只读主文档 + 少量状态侧栏：能先核对后修改，技术字段有宽度。 | 全部直接内联可编辑：少一次打开编辑器，但检查时也暴露写入控件和未保存状态。 | A；ProviderConfigurationPage 的只读/写入边界有实际价值。保留完整模型映射与敏感信息遮蔽。 |
| 供应商编辑 / 中，新建低、修正端点/模型较高 | 新建选预设 → 名称/稳定 ID → 地址、凭据、协议、模型 → 按需高级设置 → 核对保存影响。 | 单一紧凑表单，相关短字段并排，保存影响在字段后：输入宽、路径短；复杂配置通过现有展开区访问。 | 分步向导或表单 + 常驻说明栏：初次配置逐步引导，但修改单个值要跨步，说明栏挤压字段。 | A；provider-editor-desktop.png 显示固定右栏重复凭据/保存解释、压窄 ID。删除重复解释；客户端写入提醒、稳定 ID 约束、留空保留密钥及清除确认完整保留。 |
| 连接诊断 / 中、故障时高 | 选配置 → 主动运行具体检查 → 看失败阶段与响应证据 → 回到配置修正。 | 目标摘要 + 检查动作 + 结果证据：操作与观察顺序清楚，昂贵探测保留显式触发。 | 左右同时展开放置全部探针：专家比较方便，但尚未运行的配置与历史结果争夺注意力。 | A；保留当前分组和收费/认证前置条件，缺少证据时不再调布局。 |
| 市场浏览 / 中 | 搜索用途或名称 → 缩小类型/客户端范围 → 比较候选描述、发布者、兼容性和版本 → 打开详情。 | 同行搜索/筛选 + 全宽连续目录：常见动作集中，长描述空间充足；分类在行组标题中表达。 | 常驻筛选侧栏 + 每类的左标签列：适合大量复杂筛选，但当前只有类型/客户端，两个侧列吃掉目录宽度。 | A；marketplace-catalog-en-dark.png 中重复分类列和来源占据约三分之一内容宽度。来源调整为按需展开；投稿作为次要操作；不自动发送搜索请求。 |
| 市场详情 / 中 | 核对精确版本、作者、客户端、完整权限 → 选择版本历史或安装预览。 | 详情弹窗 + 固定预览动作：保留搜索上下文，打开/返回成本低。 | 独立详情页 + 常驻旁栏：适合文档型长介绍，但本产品安装依据是包元信息和权限，会多一层导航。 | A；保留版本与完整权限，不从目录直接绕过精确版本预览。 |
| 市场安装 / 低但高影响 | 核对签名指纹、权限变化和目标客户端 → 明确勾选授权 → 安装此版本。 | 一个可滚动审查体 + 固定确认区：一次检查完成；信息较多但可逐项核对。 | 多步安装向导：每页短，跨页记忆权限与目标客户端的成本高。 | A；marketplace-install-390-en-dark.png。精确摘要、指纹、过期、复核勾选和客户端范围均保留。 |
| 市场投稿/审阅 / 低 | 投稿者检查包与版本；审核者检查完整包/权限并填写意见后决定，批准与发布有独立条件。 | 原文与权限连续审查 + 固定决策区：审查长包时能随时找到决定，确认未完成仍禁用。 | 多页审核清单：适合多人分工，本产品会增加导航且失去包上下文。 | A；实际窄屏截图证实审阅决定原先埋在长内容底端。已把决定移到固定 footer，完整审查和授权条件保留。 |
| 用量概览 / 中 | 确认已应用范围 → 看已知费用/未知占比与请求完成情况 → 看时间变化 → 比较供应商或模型。 | 汇总与趋势并排、明细全宽：桌面首屏同时看到数值与变化，并更早出现可比较数据；窄屏自然上下排列。 | 汇总、图表、明细全宽纵向排列：单区宽，但当前六点图与少量汇总占据多行，比较需要反复滚动。 | A；usage-desktop-final.png 的明细仅在首屏底部出现。给趋势明确刻度；多点时保留全范围形状和原始值访问，不能把未知费用画成零。 |
| 用量请求记录 / 故障时高 | 筛选时间/客户端/供应商/模型/状态 → 比较逐次请求 → 打开失败或模型证据。 | 全宽表格 + 详情弹窗：横向比较字段直接，分页和筛选独立。 | 左请求列表 + 右常驻证据：连续深入快，但表格列被压缩，成本/时延难跨请求比较。 | A；UsagePage 的来源、状态、成本、延迟必须可比较，保留缓存键、过期请求隔离和详情信息。 |
| 用量审计分析 / 低、问题时中 | 从可观察响应识别证据质量 → 比较模型/路由 → 看单项证据；不把推测当事实。 | 分析结果 + 按需证据检查器：区分结论和原始记录，主表保留宽度。 | 全部证据嵌入每行：省展开动作，但单条 JSON 压过其他结果。 | A；现有 AuditEvidenceInspector 与完整证据入口保留。只读分析可离开，敏感写入仍保持忙锁。 |
| 探测配置 / 低 | 选择探测方式 → 了解调用/费用 → 配置并显式执行 → 查结果。 | 配置分组 + 显式运行：上下文完整，现有收费门槛清晰。 | 与只读用量同页混排：少一次切换，但容易混淆观察与主动调用。 | A；维持与概览、日志的任务区分。 |
| 模型定价 / 低、计费校准时中 | 查现有模型/价格 → 选择编辑或新增 → 核对输入/输出及缓存单价 → 保存或确认删除。 | 价格目录 + 编辑区：保留相邻模型参考；窄屏上下排列。 | 每条一张完整价格表单：编辑单行快，多模型时难扫描且误改入口多。 | A；ModelPricingModal 的未保存保护与删除确认保留，不把未知账单补成零。 |

## 统一排版和密度的产品约束

- 共享同一字号、间距、控件高度和语义 token；浅深主题只替换语义颜色，不改变布局或任务优先级。
- 中文界面使用系统中文字体回退和 1.55 左右正文行高；标题靠字重与间距区分，避免中文无意义字距。
- URL、ID、路径、模型名和哈希有独立等宽/完整值处理；自然语言正常换行。只有确实需要二维比较的表格/差异可以局部横向滚动。
- 费用、数量、日期使用等宽数字，数值列右对齐；未知、未运行、零值保持不同含义。
- 常用筛选、保存和切换保持紧凑；完整权限、客户端写入范围、不可逆删除、覆盖/回滚和过期状态按业务必要程度持续可见。
- 边界表示真正内容分组，不用卡片数量或分割线数量来定义设计。

## 内容与截图验证

本轮在具有实际业务含义的样例上检查：少量条目、大量条目、长标识符与说明、无结果/空状态，及桌面、窄窗口、中英文、浅深主题。验收不是“看起来统一”，而是能否找到候选、做有依据的比较、识别写入影响并完成原有任务。

具体已执行证据、独立截图审查结论和验证边界在最终验收记录中列出。所有独立任务页面的 A/B 比较见下表；共享弹窗随所属任务分析。


## 其余工作区的布局选择

以下覆盖剩余目的页和具有独立任务的子页。频率仍为假设。“保留”表示当前结构已支持该任务，不因另一方案存在就重建页面。比较同时考虑信息扫描、动作距离和长内容阅读。

| 页面 / 频率假设 | 真实任务与决策顺序 | A：结构与效率取舍 | B：结构与效率取舍 | 主 Agent 选择 |
| --- | --- | --- | --- | --- |
| 客户端接入 / 初次高、稳定后低 | 找到客户端 → 核对检测、接管及配置状态 → 显式接入或恢复。状态与写入范围优先。 | 客户端目录 + 所选详情：横向比较状态快，连续核对不离开目录；窄屏详情移到下方。 | 检测→连接→确认向导：首次步骤明确，但复查多个客户端需重复进入。 | A，保留目录/详情及写入确认；不把检测到应用等同已接管。 |
| 账号池 / 中、配额异常时高 | 比较供应商账号、授权、配额及绑定 → 选择可用账号 → 显式轮换或重新授权。 | 按网关/原生授权分组的比较列表 + 详情：同类状态可比，绑定和配额相邻；授权细节按需查看。 | 故障账号队列为主：排障动作近，但正常账号和整体配额被弱化。 | A；当前任务同时包括正常轮换和故障处理，没有依据把全部账号做成告警队列。 |
| 本地插件 / 中 | 搜索已安装包 → 核对版本、签名、授权客户端 → 使用工具或修改授权。 | 插件目录 + 所选包检查区：包身份与动作集中，详细权限按需展开，长参数有足够宽度。 | 客户端×插件授权矩阵：批量比较授权快，但版本、工具参数与来源难放入二维表。 | A；权限矩阵可作为将来独立需求，当前不增加第二套主导航。 |
| MCP 连接 / 中 | 按服务器查找 → 核对传输方式与客户端目标 → 编辑或启停 → 预览写入影响。 | 服务器目录 + 目标详情：一个配置的多客户端影响一起核对，避免重复编辑。 | 各客户端分开的服务器列表：单客户端浏览短，但共用服务器反复出现，易漏掉其他写入目标。 | A；保留 STDIO/HTTP 配置差异和变更确认。 |
| 共享 MCP / 使用共享工具时高 | 先看待审调用 → 核对请求者、工具、参数和权限 → 批准/拒绝；连接管理次之。 | 待审核队列 + 共享连接区，选中后完整审查：高频决定突出，批量查看请求方便。 | 每个连接下嵌套请求：追踪单一客户端方便，但跨连接待办分散、容易漏审。 | A；低频启动、策略、注册放入专用操作区；过期与精确审批绑定保留。 |
| 提示词 / 中至高 | 找到文档 → 阅读和编辑 → 判断是否保存/应用；名称与正文优先于来源细节。 | 目录 + 正文编辑：连续阅读和切换短，保留筛选上下文；窄屏逐区展开。 | 搜索结果→独立全屏编辑：单篇阅读宽，但频繁比较文档需要往返。 | A；既有未保存保护和显式应用保留。 |
| Skills / 中 | 选择已显式开启的来源 → 找到技能 → 阅读来源、路径和正文 → 决定后续使用。 | 技能目录 + 紧凑来源清单，选中后读详情：来源权限与实际路径可核验，平面目录扫描快。 | 平台/路径树常驻：来源层级直观，但深路径增加点击与缩进、压缩正文。 | A；未开启来源不扫描，来源关闭和警告的真实状态保持可见。 |
| 会话 / 高 | 按客户端、项目、标题/内容找记录 → 阅读 → 收藏/写笔记；删除是独立低频动作。 | 索引 + 页内阅读器，显式放大：打开后仍有筛选上下文，连续查阅快；短窗口有独立阅读空间。 | 项目时间轴→全页阅读：同项目连续记录自然，但跨客户端搜索与收藏检索多一步。 | A；返回目录恢复焦点，放大为用户动作；旧收藏格式及源文件删除确认保留。 |

## 收敛规则
