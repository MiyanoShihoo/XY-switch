# XY Switch 官网内容草稿

## 首屏

### 一个应用，管理你的 AI 编程工具连接

XY Switch 将供应商、模型、MCP、提示词和本地代理集中在一个 Windows 桌面应用中。代理仅在需要时开启，启动应用不会自动接管路由。

## 核心亮点

- 分应用管理 Claude、Codex 与 Gemini 工作流
- 自动探索兼容服务提供的模型
- 在 Chat、Responses、Anthropic 与 Gemini 协议之间转换
- 按供应商隔离 API 凭据
- 按需启用本地代理，并支持重试、故障转移与熔断器
- 统一维护 MCP 服务器和 Markdown 提示词

## 下载区域

正式发布时提供 Windows x64 MSI 和便携版 ZIP，并同时公开文件大小、SHA-256、签名状态与验收记录。

## 安全说明

XY Switch 本地运行。用户需自行保管 API Key，不应公开分享日志、配置或诊断材料。

## 当前范围

1.0.0 聚焦 Windows。macOS、Linux、完整 Skills 管理、完整用量统计和云同步将在后续版本评估。
