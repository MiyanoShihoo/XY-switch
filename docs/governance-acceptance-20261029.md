# 安全与验收：功能边界与验收记录（2026-10-29）

## 结论与范围

本轮在 `codex/governance-acceptance-20261029` 分支新增「安全与验收」工作区，基于会话收藏版本 `cefd0a5`。访问控制、预留预算、合成监控、配置版本和显式挂载已落地为源码，并通过本轮 Windows Rust、前端和浏览器交互回归。**真实站点端到端验收尚未通过**：模型列表可读，Responses 与 Chat 上游配置各做一轮检查，均在首个生成请求收到 HTTP 500 后停止；Chat 补测的事件记录明确为上游 HTTP 500。版本仍为 **1.1.0**，本轮没有重建/发布安装包，不代表其他平台或原生安装流程已经验收。

测试对象为当前开发副本、隔离内存数据库、临时目录及回环代理；真实网络仅针对用户提供的测试站点，不扫描其他资产。浏览器 UI 使用独立 profile 和模拟 IPC，不读个人客户端配置。功能入口和操作步骤见[中文用户手册](user-guide-zh.md#使用安全与验收未发布2026-10-29)及[英文用户手册](user-guide-en.md#use-safety-and-acceptance-unreleased-2026-10-29)。

## 已实现的功能与默认值

| 功能 | 实际行为 | 默认值与限制 |
| --- | --- | --- |
| 访问控制 | 本地随机令牌、SHA-256 摘要存储、到期/撤销；`proxy` 和只读 `monitor` 权限 | 模型入口默认兼容模式、不强制认证，页面明确提醒；状态接口始终认证 |
| 请求限流 | 所有令牌及鉴权失败共享每分钟计数；流式响应结束/丢弃前持有并发许可 | 默认 120 次/分钟、8 并发；`GET /health` 仅做最小存活检查，豁免令牌与额度 |
| 预留硬预算 | SQLite 事务在每次实际派发前预扣 Token 与微美元；重试、故障转移、模型复核均单独预扣 | 默认关闭；默认每日 100,000 Token、1 USD，单次输入预留 4096、输出上限 512 |
| 单次验收 | 回环 HTTP → 实际代理鉴权/预算/路由/转换 → 上游 → 内容断言 → 收据 | 需要运行中的代理、已启用预算和 `ALLOW PAID CHECKS` 确认；不执行返回工具 |
| 计划监控 | 显式启用后按计划检查；手动与计划共享持久化日次数；重启不补跑历史任务 | 默认关闭；默认 30 分钟、10 次/UTC 日；范围 5–1440 分钟、1–100 次/日 |
| 配置版本 | 手动快照、完整 diff、当前/目标摘要校验、同事务备份与回滚 | 最多 200 个、单个 8 MiB；先停止代理并恢复接管，确认文字 `ROLLBACK` |
| 显式挂载 | 原生目录授权、规则文件 diff、原文备份、原子替换、受保护回滚 | 仅根目录 `CLAUDE.md` / `AGENTS.md` / `GEMINI.md`；预览 5 分钟、一次有效，确认文字 `WRITE FILE` |
| 本机只读与审计 | 概览、用量预留、供应商状态、验收收据；策略与文件操作审计 | 移动端只读、不启动计划；审计保留 2000 条/显示最近 100 条，收据保留 30 天/显示最近 100 条 |

### 访问与凭据

- 令牌只在创建成功时显示一次，不进入 React Query mutation cache 或 localStorage。数据库只保存摘要；由接管流程使用的管理令牌保存到原生凭据库。
- `monitor` 不能调用模型，即使兼容模式未强制模型认证；未知 `xy_` 令牌也不会当作兼容凭据放行。重复/冲突认证头会被拒绝。
- `GET /xy/status` 只在回环地址提供脱敏状态；不返回上游端点、密钥、响应正文或原始错误。它不是互联网可访问的远程管理 API。
- 本地 Host/Origin/跨站请求防护保持启用。默认限流现在也覆盖鉴权失败，健康检查除外。
- 共用 HTTP builder 禁止隐式重试，避免传输库绕开显式预算预扣；实际代理取出的上游密钥使用 `Zeroizing` 包裹。这不保证清除 HTTP 库内部所有临时副本。

### 预算准确性边界

**硬限制针对本机的持久化预留账本，不是供应商最终账单或所有模型真实 Token 数的保证。** 输入按 UTF-8 大小做保守准入检查，但它不是任意 tokenizer 的数学上界；供应商隐藏推理、计费规则及缺失用量仍可能不可知。

- 必须有**精确实际模型 ID 的自定义价格**；参考价、前缀/模糊匹配和缺价不能授权请求。缓存价格按最高适用输入价预留，费用向上取整到微美元。
- 只允许当前支持的有界纯文本与本地函数工具。多模态、远端会话/历史、内建联网工具、多候选和未知载荷字段被拒绝，不做静默估价放行。
- 原生 Gemini **上游**尚未支持硬预算，因此启用预算时拒绝；Gemini **客户端**适配路径可以用于支持的上游，二者不同。
- Chat 使用 `max_completion_tokens` 强制输出上限，旧网关可能不兼容。不能以此推断本轮真实 HTTP 500 的原因。
- 失败、取消和未知用量均不退款；重启、改价或修改限额不会清零已预留额度。日界线是 UTC，关闭再开启预算也不重置同日记录。

### 验收与告警边界

支持 `chat`、`stream`、`tools`、`responses`、`anthropic`、`gemini` 六种客户端模式。HTTP 200 本身不算成功：文本必须精确匹配，完成原因必须有效，SSE 必须结束，工具名称/参数必须符合预期；工具不被执行。

合成请求禁用代理重试、故障转移、用户请求覆写和额外收费复核；普通文本最多 16 个输出 Token，工具模式最多 48 个，60 秒超时、响应上限 1 MiB。上游返回的模型字段只作自报证据，不证明模型权重身份。计划只在桌面应用运行期间尽力执行，退出/挂起期间不保证触发；失败/恢复转变写入审计，相同状态不重复报警，未接入远程推送通知。

### 版本与文件边界

- 配置快照覆盖供应商、提示词、自定义定价、当前供应商和代理设置；不覆盖凭据库、MCP、会话收藏、外部文件、访问/预算/监控策略或安全账本。后创建的供应商保留并停用，不删除历史。恢复后代理保持停止。
- 快照和 diff 可能含用户写入配置文本的敏感内容；不是加密同步包，也不是完整配置/凭据备份。
- 显式挂载只读取选中的本地内容，保留托管块外的现有文字。只挂载已授权源中的 `SKILL.md` 文本，不复制脚本/资源、不安装依赖、不执行任何命令。
- 原生目录选择器授予的是内部 handle，renderer 不能传任意写入路径。应用前检查目录/文件类型、原始内容和预览有效期；先保存完整原文，再替换文件。旧备份只在当前文件仍匹配那次写入结果时允许回滚。
- 不宣称抵抗拥有相同操作系统权限的恶意进程进行所有文件系统 TOCTOU 竞争。备份包含项目原文，仍是本机敏感数据。

### 真实站点记录

测试站点为用户提供的 [SuperAPI](https://superapi.buzz/)。选择网关列表中的 `gpt-5.5`，先用 `openai_responses`，再以 `openai_chat` 做有界补测；两轮都从本地 Chat 路径进入完整代理。网关自报模型 ID 不代表官方型号或权重认证。

每轮首个检查都收到 `local_http_500` 并立即停止；输入/输出用量及返回模型均未知。补测记录为 `upstreamEvents=[{errorKind:"upstream_status",statusCode:500,retryCount:0}]`，说明本次 500 来自 HTTP 上游响应，而非预算拒绝或本地鉴权。没有原始上游错误正文，仍不能判断网关内部故障、模型可用性或参数兼容问题。原 Responses 轮没有该事件附加信息，不能用补测反推那一轮的来源。

共两次实际生成尝试，每轮独立内存账本各预留 **1040 Token**（1024 输入预留 + 16 输出上限），按测试用输入 1 USD/百万、输出 2 USD/百万价格各预留 **1056 微美元**；两轮合计 2080 Token / 2112 微美元。它们是**测试准入价格和预留数，不是供应商报价、实际计费或账单**。

补测执行审批曾因服务限流未完成，稍后经正常审批重试后执行；审批失败期间未发送请求，不计为站点失败或新的收费尝试。保留失败收据，等待供应商错误原因或兼容参数得到确认后再有界复测，不进行无目的重复收费。

live 测试使用 Windows 一次性 named pipe 输入凭据，仅随机 pipe 名称进入环境变量；密钥不写源码、命令行、日志、报告、Git 或生产凭据库。测试数据库和 API key provider 都在内存中，隔离代理使用随机回环端口，TLS 校验保持开启，禁重定向及隐式重试。

## 复现与本地证据位置

在已配置平台 SDK 的开发终端、仓库根目录运行（不依赖真实 API key）：

```powershell
cargo test --manifest-path src-tauri/Cargo.toml --lib --offline --locked -- --quiet
pnpm test
pnpm build:renderer
```

浏览器测试需要单独启动 Vite 和**独立 profile** 的 Edge/Chrome CDP，不连接个人浏览器。开发服务示例：

```powershell
pnpm dev:renderer --host 127.0.0.1 --port 1431 --strictPort
```

在另一个终端，将独立浏览器的 CDP 设为 `127.0.0.1:9231` 后运行：

```powershell
$env:APP_URL = 'http://127.0.0.1:1431'
$env:CDP_ENDPOINT = 'http://127.0.0.1:9231'
pnpm test:ui:governance
```

脚本创建并关闭自己的 CDP target。结束后关闭独立浏览器与 Vite。`QA_ONLY` 可选择单项，但会覆盖结果文件；完整结论应以不设置 `QA_ONLY` 的全量结果为准。

默认 Rust 测试不会发起 live 请求。Windows live 测试为 `governance_live_acceptance_from_one_shot_pipe`，显式 `--ignored` 才可运行；还必须由一次性凭据管道供给严格 JSON 输入。`discover` 只查模型列表；`acceptance` 要求 `ALLOW PAID CHECKS`、明确模型/上游格式，最多六次检查，HTTP 错误/无 HTTP 状态立即停止，合计输出上限 128 Token。不要用 shell 历史、文件或凭据环境变量代替管道。
