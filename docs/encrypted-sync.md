# 手动端到端加密配置交换

> 开发分支功能：不包含在 1.2.0 发布提交 `b51387f9604d0ef19a8e06202504dc42b294ce03` 中。当前实现是桌面端手动导出/导入 `.xysync` 文件，不是后台云同步服务。

## 在两台设备间交换配置

1. 在源设备打开「设置 → 加密配置同步」，预览导出内容。检查供应商名称、地址路径、模型映射、收藏标识及自定义价格，避免把敏感文本填在这些允许同步的字段中。
2. 输入至少 12 个 Unicode 字符、至多 1024 字节 UTF-8 的口令，确认已检查预览，输入 `EXPORT`，再通过原生文件对话框保存一个新的 `.xysync` 文件。已有文件不会被覆盖。
3. 自行将加密文件传给另一台设备；通过独立途径提供口令。软件没有云端账户、远程上传、定时上传或口令找回服务。
4. 在目标设备导入文件、输入口令并检查解密预览。每一项差异都必须选择「保留本机」或「采用传入值」；可以用「仅接受新增项」给新增项赋值。超过 50 项时分页显示，但提交仍校验完整选择集合。
5. 停止本机代理并退出接管，检查所有选择后输入 `IMPORT`。成功导入会在同一 SQLite 事务中创建本地备份与审计记录。
6. 新供应商默认禁用且没有凭据。在本机单独配置凭据、检查地址后再手动启用。收藏只同步标识，另一台设备没有相应会话文件时，不会凭空恢复会话正文。

预览票据 5 分钟后失效、最多同时保留 4 个，且只能使用一次。取消、过期、重复提交或预览后本机状态变化，都需要重新预览。同步功能不会写入 CLAUDE.md、AGENTS.md 或 GEMINI.md，也不会执行会话恢复命令。

## 哪些数据会同步

| 数据 | 行为 | 边界 |
| --- | --- | --- |
| 供应商配置 | 同步逻辑 UUID、名称、类型、应用分组、地址、模型、协议、完整 URL 标志和模型映射 | 不复用其他设备的本机供应商/凭据 ID；不含启用状态 |
| 收藏 | 同步 providerId / sessionId 标识组合 | 不同步正文、标题摘要、会话目录或文件 |
| 自定义定价 | 合并模型自定义价格 | 不把参考价格快照、历史用量或账本打包；不重算历史费用 |
| 系统凭据 | 不访问系统凭据存储 | 不导出、导入或复制 API Key |
| 高级配置及其他功能 | 不进入交换文件 | 请求头、advanced overrides、TOML、MCP、提示词/Skills、访问控制、安全策略及预算账本均不在白名单内 |

URL 拒绝用户名、密码、query 和 fragment。允许的名称、模型名与地址路径仍是自定义文本；白名单不能识别所有人为嵌入的秘密，完整预览仍然必要。导出不等于通用脱敏工具。

原生桌面收藏会从 localStorage v1 一次性事务迁移到 SQLite；原始文本保存在本机数据库，原 localStorage 不删除、不改写。迁移标记防止下一次启动把已删除收藏复活；读取或迁移失败时，文件交换会被阻止，而不是把错误当成空收藏。浏览器和移动端继续使用原有 localStorage 收藏路径；它们不开放原生加密文件写入。

## 冲突与回滚

同步是 **merge-only**：文件中缺少某项不会删除本机项目，也没有删除墓碑传播。

- 供应商同步 UUID 独立于本机 UUID。来自另一台设备的新供应商获得新的本机 ID，并默认禁用。
- 地址、类型或协议目标发生变化时，保留原供应商及其凭据，并创建一个禁用副本，避免旧凭据被新目标继承。
- 目标相同的更新只修改白名单字段，保留本机 advanced 配置。未知、重复、遗漏的冲突选择全部拒绝。
- 导入前对本地完整配置状态计算哈希，防止旧预览覆盖新状态。预览可能为本机记录分配内部同步 UUID；这不是数据库绝对零写入，但不会应用传入配置。
- 保留最近 10 份导入备份，每份最多 8 MiB。回滚也需要完整预览并输入 `ROLLBACK SYNC`，且要求代理停止、接管退出。
- 备份之后本机又有变化时拒绝旧回滚，避免覆盖后续操作。新增供应商回滚后仍保留为禁用状态，用量和历史记录不删除；价格来源与时间恢复，但历史费用不重算。

**本地备份不是加密同步文件。** 快照、哈希与回滚会读取本机 advanced 配置，备份保存在本机 SQLite 中，可能包含用户原有敏感文本。不能声称功能完全“不读取高级配置”，也不能把本机数据库直接当作安全的跨设备导出物。

## 文件与加密格式

| 项目 | 当前实现 |
| --- | --- |
| 认证加密 | AES-256-GCM |
| 口令派生 | PBKDF2-HMAC-SHA256，600,000 次迭代 |
| 文件头 | 8 字节 `XYSYNC01` + 32 字节随机 salt + 12 字节随机 nonce；完整头部作为 AAD |
| 密文 | UTF-8 JSON 经加密后附带 16 字节认证 tag |
| 大小限制 | 明文最多 8 MiB；文件最多 8 MiB + 68 字节；解密及 KDF 前先做结构/长度检查 |
| 文件操作 | 只接受原生对话框本地路径；拒绝非普通文件及目标 symlink/reparse；新建模式写入，不覆盖 |
| 并发 | KDF 串行；导入/回滚受代理配置锁与接管状态保护 |

不同导出使用独立随机 salt/nonce。错误口令、头部、密文或 tag 篡改会失败关闭，不产生部分配置导入。文件扩展名不是安全验证依据。部分 Rust 派生密钥/明文缓冲区使用 Zeroizing；不承诺 JavaScript、运行时或密码库的全部内存副本都可清零。口令不放入 React Query 或 localStorage，操作开始时清空输入框。

## 常见失败

| 提示/现象 | 处理 |
| --- | --- |
| 口令不正确或文件被修改 | 不会更改本机配置；确认原始文件和口令后重新预览 |
| 预览已过期/已使用/本机状态变化 | 关闭旧预览，重新生成；不自动重试写操作 |
| 代理运行或接管未退出 | 先停止对应功能，再重新预览并确认 |
| 收藏迁移失败 | 修复本机收藏读取/数据库错误后重试，不跳过迁移保护 |
| 文件已存在、超限或为链接 | 选择新的普通本地文件；不自动覆盖或跟随链接 |
| 数据已保存，但界面刷新失败 | 写入已经完成；不要重复导入，先刷新界面。收藏、主视图和备份列表各自刷新，单项刷新失败不掩盖成功提交 |
