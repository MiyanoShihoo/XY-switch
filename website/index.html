A clear place for the moving parts.

01

Providers & models

Manage endpoints, credentials, discovery and model mappings. Saved, current and connected are distinct states.

02

MCP & local resources

Manage MCP servers and local prompts. Opt in to desktop Skill sources; removing a reference does not delete its source.

03

NATIVE BUILDS, EXPLICIT LIMITS

Choose your platform. Read its scope.

DESKTOP / X64

Windows x64

NSIS EXE / MSI. Unsigned; WebView2 required. No portable ZIP.

DESKTOP / X64

Linux x64

DEB / AppImage. Ubuntu 22.04 build; compatible libraries and unlocked Secret Service required.

DESKTOP / UNIVERSAL

macOS Universal

Intel + Apple Silicon, App ZIP / DMG. Ad-hoc signed; not notarized.

MOBILE / UNIVERSAL

Android 7.0+

ARM64 + x86_64 APK, development-signed. Cross-build in-place upgrades are not guaranteed.

MOBILE / SIMULATOR ONLY

iOS Simulator

ARM64 simulator ZIP, not an iPhone IPA. Device builds need Apple signing and provisioning.

Downloads include checksums and a release verification report. Native runtime gates and synthetic browser tests are different evidence; ARM64 Android package checks are not real-device tests.

What this release does not claim

  • Desktop takeover supports Claude Code, Codex and Gemini CLI—not every displayed client group.
  • Prompts are managed locally, not synchronized to CLAUDE.md / AGENTS.md / GEMINI.md. Full native conversation management is not implemented.
  • Mobile manages only its own sandbox. Other apps’ CLI/Skills/session directories and persistent background proxy operation are outside its guarantees.

Start with the facts. Keep control.

Follow the user guide, build from source, or inspect exactly what a release verified. Normal configuration exports are not full credential backups.
